# Decisoes do projeto

Esta pasta registra decisoes relevantes que afetam o projeto. O objetivo e preservar o contexto, e nao apenas o resultado.

## Registro de uma decisao

Novas decisoes devem informar, quando aplicavel:

- o que foi decidido;
- por que foi decidido;
- quando foi decidido;
- quem participou;
- impactos, alternativas e pendencias.

Decisoes ainda nao tomadas devem permanecer como **A definir**, sem antecipar escolhas da equipe.
