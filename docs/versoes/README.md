# Versoes do sistema

As versoes demonstram na pratica o desenvolvimento incremental. A V1 representa a primeira implementacao disponibilizavel; as versoes seguintes representam a evolucao do sistema depois que ele estiver em funcionamento.

## Versoes

- [V1 - Primeira versao disponibilizavel](v1.md)
- [V2 - Evolucao](v2.md)
- [V3 - Evolucao](v3.md)
- [V4 e posteriores](v4-e-posteriores.md)

Para cada versao, a equipe devera registrar o objetivo, o escopo priorizado, o estado das entregas, as validacoes e o que foi aprendido.
