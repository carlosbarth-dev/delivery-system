# Processos de trabalho

A equipe pretende trabalhar de forma colaborativa, profissional e compativel com o contexto academico, mantendo apenas os registros que ajudarem o projeto a avancar.

## A definir pela equipe

- fluxo de desenvolvimento;
- organizacao das tarefas;
- branches e integracao do trabalho;
- commits e Pull Requests;
- revisao de codigo;
- testes e validacao;
- acompanhamento de riscos e impedimentos;
- planejamento e acompanhamento das versoes.

As regras devem ser simples, compreendidas por todos e revisadas quando deixarem de ajudar o trabalho.

Consulte tambem [Git e colaboracao](git.md).
