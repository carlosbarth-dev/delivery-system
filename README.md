# Parte do Pedro — módulo independente

Esta branch contém somente a minha contribuição: o módulo em `backend/pedro_integration/`,
seus testes e a documentação. Não há cópia da `main`, do front-end ou do código dos colegas.

O módulo roda sozinho com SQLite para desenvolvimento. Para entender o que ele faz,
como testar e o que ainda depende do grupo, leia
[o guia do módulo](backend/pedro_integration/README.md).

Não publique o arquivo `.env` real. Para juntar esta parte ao projeto,
a equipe pode aplicar só o commit do módulo, sem copiar toda a branch.
