# V3 - Evolucao do sistema

Representa uma nova evolucao do sistema em funcionamento, seguindo as necessidades identificadas depois das versoes anteriores.

## A definir pela equipe

- novas funcionalidades;
- melhorias;
- correcoes;
- mudancas decorrentes de feedback dos usuarios;
- novos requisitos;
- criterios de aceite;
- validacoes e testes;
- data e estado da entrega.
